=======================================

Goal:
Use Prof. Hohmeyer's existing RE100 Excel model and generate the most accurate Santiago, Cabo Verde input pack possible so the model can run for Santiago. Do not build a new energy model.

Core requirements:
- Inspect `RE100 Model Version 1.0 2026.xlsx`.
- Identify yellow/user-editable inputs and required 8760-hour data vectors.
- Use 2023 as the base year because it has 8760 hours.
- Do not hallucinate or invent missing numbers.
- Do not silently use Barbados values for Santiago.
- Keep default model values only when they are generic technology assumptions and label them clearly as defaults.
- Assign every input a value, unit, target cell/range, source, confidence class, and simple explanation.

Required model input ranges:
- Hourly load: `Hourly Load!F7:F8766`
- Hourly wind speed: `Wind and Solar Input!D5:D8764`
- Hourly solar radiation: `Wind and Solar Input!E5:E8764`

Load method:

- Prefer `Equivalent Week Profile Load`.
- Map month and weekday to equivalent day with:
  `equivalent_day = (month - 1) * 7 + weekday_number`
- Scale the resulting 8760-hour shape to Electra's official Santiago 2023 annual production:
  `263,839,489 kWh = 263,839.489 MWh = 263.839489 GWh`
- Validate against Electra's reported Santiago peak:
  `41.833 MW on 28 August 2023 at 15:00`
- Do not claim certified hourly SCADA accuracy.

Weather method:
- Generate 8760-hour wind and solar vectors for Santiago.
- Prefer public measured Santiago data if available.
- Otherwise use defensible public hourly simulation or reanalysis sources such as Open-Meteo Historical API, Renewables.ninja, or NASA POWER.
- Document coordinates, source endpoint, units, conversions, and confidence class.

Electricity Maps rule:
- Use Electricity Maps Cabo Verde zone CV only as a national hourly shape benchmark if available.
- Do not claim Electricity Maps gives official Santiago hourly meter data.
- Cabo Verde is treated as a national zone benchmark and not direct Santiago SCADA truth.

Outputs:

- `Santiago_RE100_Input_Audit.xlsx`
- `Santiago_RE100_Input_Audit.csv`

Confidence classes:
- A = official measured or official annual data
- B = official report value transformed by clear calculation
- C = scientific dataset or reanalysis weather source
- D = model default or scenario assumption
- E = missing or not used

This is a Santiago input pack for Prof. Hohmeyer's RE100 model. It is not a new model. Values marked D are scenario assumptions or model defaults, not verified Santiago measurements.
